# HN Workflow

How to find and engage on Hacker News using BrowserAct.

## Finding Posts

Search HN for relevant discussions:

```
https://hn.algolia.com/?q=<query>&dateRange=pastMonth&type=story
```

Look for:
- "Ask HN" posts about your domain
- Show HN posts from competitors
- Posts discussing the problem you solve

## Extract

From each relevant post:
```
title: Post title
author: Username
points: Score
comments: Number of comments
url: Post URL
```

## Engagement Rules

- Add genuine value — answer questions, share insights
- Never pitch your product directly in comments
- If someone asks for recommendations, mention your product naturally
- Build reputation over time
- Follow HN culture — be thoughtful, not promotional
