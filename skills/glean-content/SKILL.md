# Glean Content

Write content that attracts the target audience. Saved as files for founder to publish.

## Files

- `references/content-formats.md` — Templates for different content types
- `references/writing-tone.md` — How to match the founder's voice

## Behavior

### 1. Read context

- `./glean-data/profile.md` — What the product is
- `./glean-data/target-audience.md` — Who they're writing for
- `./glean-data/strategy.md` — Messaging angle

### 2. Ask founder

- "What topic do you want to write about?"
- "What platform? (X thread, LinkedIn post, blog post, email)"
- "What format? (educational, story, opinion, how-to)"

### 3. Research (optional)

If the topic needs context:
- Web search for current trends, data, examples
- Check what competitors are saying
- Find relevant stats or case studies

### 4. Write draft

Read `references/content-formats.md` for templates. Read `references/writing-tone.md` for voice guidelines.

Write the draft. Match the founder's tone. Target the audience's pain points.

### 5. Save to file

Save to `./glean-data/content/<date>-<topic-slug>.md`

Format:
```markdown
# [Title]

**Platform:** [LinkedIn / X / Blog / Email]
**Status:** draft
**Topic:** [topic]

---

[Content here]

---

## Notes
- [Any suggestions for the founder]
- [Best time to post]
- [Hashtags or tags to use]
```

### 6. Present to founder

"Here's a draft for a LinkedIn post about [topic]:
[Show the draft]
Saved to ./glean-data/content/2025-01-15-scaling-challenges.md
Edit it and publish when ready."

### 7. Learn from results

If the founder says a post performed well, note it in strategy.md under "what's working."
If a post flopped, note what to avoid.

## Rules

- Never publish on behalf of the founder — save drafts only
- Match the founder's tone, not a generic "AI" voice
- Lead with the audience's problem, not the product
- Keep it concise — respect the platform's format
- Include a clear CTA when appropriate
- Save every draft — founder edits and publishes
