# Content Formats

Templates for different content types.

## X/Twitter Thread

Structure: Hook → Problem → Solution → CTA

```
Hook (1/5): [Attention-grabbing first tweet]

Problem (2/5): [Describe the pain point]

Solution (3/5): [Your approach or insight]

Example (4/5): [Concrete example or case study]

CTA (5/5): [What you want them to do]
```

Rules:
- 5-7 tweets per thread
- First tweet must hook
- Each tweet under 280 characters
- Use numbers and specifics
- End with clear CTA

## LinkedIn Post

Structure: Hook → Story → Insight → CTA

```
[Hook line — attention-grabbing]

[Story — personal or observed experience]

[Insight — what you learned]

[CTA — question or call to action]
```

Rules:
- Under 1300 characters
- First line must hook (only 2 lines show before "see more")
- Use line breaks for readability
- End with a question to drive comments

## Blog Post

Structure: Title → Intro → Problem → Solution → Examples → CTA

```
# [Title]

## Introduction
[Why this matters]

## The Problem
[What's broken]

## The Solution
[How to fix it]

## Examples
[Concrete examples]

## Conclusion
[Summary + CTA]
```

Rules:
- 800-1500 words
- Use headings and subheadings
- Include examples and data
- End with clear CTA

## Email Newsletter

Structure: Subject → Hook → Value → CTA

```
Subject: [Specific, curiosity-driven]

[Hook — why they should read]

[Value — insight, tip, or story]

[CTA — what you want them to do]
```

Rules:
- Under 300 words
- One clear CTA
- Personal, conversational tone
- Mobile-friendly formatting
