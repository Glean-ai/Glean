# Writing Tone

How to match the founder's voice.

## Detecting Tone

From profile.md tone field and website content:

- **Formal**: Professional language, complete sentences, no contractions
- **Casual**: Conversational, contractions, occasional slang
- **Technical**: Jargon-heavy, precise, data-driven
- **Builder**: Direct, action-oriented, no fluff

## Matching Tone

Read the founder's existing content (website, social media, previous drafts) and mirror:

- Sentence length
- Vocabulary level
- Use of jargon
- Humor level
- Emoji usage
- Formatting style

## Rules

- Never sound like "AI" — avoid generic phrases
- Match the founder's energy, not a template
- If unsure, default to casual-professional
- Read the tone section in profile.md before writing
