# Discovery Prompts

Questions to ask the founder during setup. Only ask what couldn't be auto-discovered.

## Product Questions

- "What does your product do? One sentence."
- "Who is it for? Be specific."
- "What problem does it solve for them?"
- "What makes it different from alternatives?"

## Business Questions

- "What's your pricing?"
- "Do you have any users or customers yet?"
- "What have you tried for marketing or sales?"
- "What worked? What didn't?"

## Channel Questions

- "Where does your audience hang out online?"
- "Are you on LinkedIn, X, email, or any communities?"
- "Which channel do you want to start on?"

## Tone Questions

- "What's your tone — formal, casual, technical?"
- "Can you show me an example of how you usually write?"

## Auto-Discovery

Before asking anything, try to learn automatically:

1. If website URL provided → fetch it, extract product info, tone, positioning
2. If code in working directory → read package.json, README, main entry
3. If GitHub profile → check repos, README, recent activity
