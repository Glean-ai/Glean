# Channel Selection Guide

Which channels work for which audiences.

## Channel Matrix

| Audience | Best Channel | Why |
|----------|-------------|-----|
| Developers | X/Twitter, GitHub | They live here |
| Business owners | LinkedIn, Google Maps | Professional context |
| Local businesses | Google Maps | Location-based |
| Consumers | Email, X/Twitter | Broad reach |
| Tech founders | X, Reddit, HN | Builder communities |
| Marketers | LinkedIn | Professional network |
| Freelancers | LinkedIn, X | Both work |

## Channel Capabilities

| Channel | Find Leads | Send Messages | Track Results |
|---------|-----------|---------------|---------------|
| LinkedIn | Yes | Yes (connection requests, InMail) | Yes |
| X/Twitter | Yes | Yes (DMs after engagement) | Yes |
| Email | Yes (find addresses) | Yes (compose, send) | Yes |
| Reddit | Yes (find discussions) | Limited (comments, not DMs) | Partial |
| HN | Yes (find posts) | Limited (comments) | Partial |
| Google Maps | Yes (local businesses) | Yes (email, contact forms) | Yes |

## Starting Recommendations

- **B2B SaaS** → LinkedIn first, email second
- **Developer tools** → X first, Reddit/HN second
- **Local business** → Google Maps first, email second
- **Consumer product** → X first, communities second
- **Freelancer/consultant** → LinkedIn first, X second

## When to Add Channels

- After 20+ leads on first channel
- After first paying customer
- When first channel response rate drops below 10%
- When founder asks to expand
